# Infographic release checklist

- [ ] The title and takeaway express the approved learner question and claim.
- [ ] The title clearly names the subject or concept, not only a generic action or question.
- [ ] The content brief has a recorded `READY` review for factual accuracy and explanatory richness.
- [ ] The visual brief has a recorded `READY` review against the content brief.
- [ ] Every important fact, number, unit, formula, and example matches the content brief.
- [ ] Arrows, groups, order, and visual metaphors express the actual mechanism.
- [ ] All exact labels are present and legible at expected display size.
- [ ] No unsupported detail, unrelated history, syllabus label, exam year, or coverage marker appears.
- [ ] The page has one clear reading path and a dominant explanatory visual; supporting details stay on-topic and the layout avoids generic equal-card grids.
- [ ] Useful supporting context was considered; include a grounded analogy or other detail only if it makes this explanation clearer, and do not require metaphor for its own sake.
- [ ] Every support selected in the visual brief is clearly represented in the image; a mention in copy alone is insufficient.
- [ ] The shared approved SVG signature is in the reserved lower-left footer, correctly scaled and unchanged.
- [ ] The final filename is descriptive English kebab-case; source brief, visual brief, and prompt are kept beside the output.
- [ ] Pinterest title, short description, and tags are English and saved separately from the image.
- [ ] Website alt text is concise, English, and describes the actual visual rather than repeating promotional copy.
- [ ] Remaining uncertainty or QA issues are recorded; do not claim publish-ready while material issues remain.
