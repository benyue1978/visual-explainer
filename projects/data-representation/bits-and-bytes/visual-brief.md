# Bits and Bytes — Visual Brief

## 目标与核心结论

- **受众：** 初次学习数字数据表示的学校阶段学习者及其教师；图面英文。
- **学习目标：** 学习者能说明每增加一个独立 bit，可能的 bit patterns 数就加倍，并能解释 8-bit byte 有 256 种可能的 pattern。
- **核心结论：** 每个 bit 有两个可能值，因此 `n` 个 bits 形成 `2^n` 种 pattern；一个 byte 是 8 bits，所以有 256 种 pattern。
- **内容边界：** 解释可能的位序列数量，不指定这些序列代表的字符、数值或指令；不讲容量前缀、数值范围或编码规则。
- **读者可见内容：** 只出现概念、解释、准确术语和例子。不出现 syllabus 名称或代码、年份、章节号、考试徽标或覆盖率标记。

## 阅读路径

1. 从一个 bit 的两个可能值 `0` 与 `1` 开始。
2. 展示每增加一个 bit，每种已有 pattern 都分成两个后续 pattern。
3. 用 1、2、3 个 bits 展示 pattern 数从 2 到 4 再到 8。
4. 将同一倍增规则延伸到 8 bits，并明确标注 `1 byte = 8 bits` 与 `2^8 = 256 patterns`。
5. 以一句简短边界说明收束：pattern 是位序列；它表达什么，要看解释规则。

## 主视觉机制

用一棵从左向右展开的三层二叉分支图表现组合数翻倍。根部为起始位置；每个分支节点均分成 `0` 和 `1` 两种后续。依次标出 1-bit、2-bit 和 3-bit 的状态数量，并让最右层清楚呈现 8 个三位 pattern。树的连接关系必须让人看出：每条旧路径都会继续分成两条，而不是只增加两个总结果。

8-bit 结果作为主视觉的结果标注或相邻放大标记出现，不绘制全部 256 个 pattern。通过大号 `8 bits = 1 byte` 与 `2^8 = 256 patterns`，表示三层示例遵循同一规则扩展到 8 位。

## 构图建议

- **画幅：** 本版为竖版 3:4，为统一署名留出独立页脚；后续图可采用其他画幅，但仍需保留一致的左下署名安全区。
- **标题：** 顶部使用编辑性标题，直接提出学习者问题。
- **主图区：** 页面中央偏左或中央为三层分支图，按清晰的左到右阅读方向组织；三个阶段分别显示 bit 数与 pattern 总数。
- **例子区：** 末层显示完整的 3-bit patterns：`000 001 010 011 100 101 110 111`。用等宽字体并留足间距，避免挤成难读的一行。
- **结果区：** 页面下部突出 `1 byte = 8 bits`，以及 `2^8 = 256 patterns`。让“256 patterns”成为次级视觉焦点。
- **边界提示：** 底部以简短文字提醒 pattern 本身不携带固定含义，保持低于主结论的视觉权重。
- **品牌页脚：** 底部独立留白区放置统一 SVG 署名；不与解释文案争抢空间。
- 不把每个信息拆成等尺寸卡片；分支树是唯一主视觉，其余标注围绕它组织。

**Title**

> How Many Patterns Can Eight Bits Hold?

**Labels**

- `A bit has 2 possible values: 0 or 1`
- `1 bit → 2 patterns`
- `2 bits → 4 patterns`
- `3 bits → 8 patterns`
- `Each new bit doubles the number of patterns.`
- `1 byte = 8 bits`
- `One possible pattern: 00000000`
- `2^8 = 256 patterns`
- `A pattern is a sequence of bits. A rule gives it meaning.`

**3-bit example**

- `000`
- `001`
- `010`
- `011`
- `100`
- `101`
- `110`
- `111`

## 准确性与制作约束

- 每一个 bit 有且只有两个可能值：`0` 与 `1`。
- pattern 数量按独立选择相乘：1、2、3 个 bits 分别为 2、4、8 种；8 bits 为 256 种。
- 明确 `1 byte = 8 bits`。不加入这个定义的历史说明或例外介绍。
- 不要暗示一个 pattern 天生对应一个特定字符或数值；固定含义需要另一个表示或编码规则。
- 不绘出或暗示 8-bit 的全部 256 种 pattern 均在此展示。
- 禁止添加来源没有支持的数值、术语、符号和示例。
- 图像模型可能误写文字；正式成图时应将公式、数字和长文案置于可编辑文字层，并逐项按内容 brief 校对。
