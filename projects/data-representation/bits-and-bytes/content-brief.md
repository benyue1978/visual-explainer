# Bits and Bytes — How Many Patterns Can Eight Bits Hold?

- **状态：** 内容已复核，进入 visual brief 与构图规划
- **位置：** Bits, Bytes & Magnitudes 模块的第一项正式内容

## 读者与先备知识

- **目标读者：** 初次学习数字数据表示的学校阶段学习者及其教师。
- **读者已经知道：** 十进制数位和整数乘法；不假设已学过 binary 或指数记法。
- **需要建立的词汇：** bit、bit pattern、byte、possible pattern。
- **学习者的问题：** 几个只有 0 或 1 的位置，怎样形成更多不同的组合？

## 学习目标与范围

- **学习目标：** 学习者能解释为什么每增加一个独立 bit，可能的 bit pattern 数量就加倍，并能算出一个给定 bit 数能形成多少种 pattern。
- **范围：** bit 的两种可能状态；多个 bit 形成序列；`n` 个独立 bit 有 `2^n` 种 pattern；现代数据表示中一个 byte 为 8 bits，因此有 256 种不同 pattern。
- **不在范围内：** binary/decimal capacity prefixes（如 kB 与 KiB）、较大容量单位换算、unsigned/signed 数值范围、文字或其他数据编码规则。这些是相邻而不同的学习问题，后续分别规划。
- **模块与知识连接：** 为数字、文字、图像和声音模块建立共同的 bit-pattern 概念；之后再说明不同规则怎样给 pattern 赋予意义。
- **核心结论：** 每个独立 bit 提供两个选择，所以 bit 数每增加一个，可能的 pattern 数就翻倍；8-bit byte 有 256 种不同 pattern。

## 概念模型

1. **对象：** 有固定数量位置的 bit sequence。
2. **输入：** 每个位置可取 `0` 或 `1`。
3. **过程与状态变化：** 每增加一个位置，每种已有组合都能分别接上 `0` 和 `1`，组合总数因此乘以 2。
4. **输出：** 给定 bit 数所能形成的不同 pattern 数。
5. **关键关系：** `n` 个独立 bit → `2 × 2 × ... × 2`（共 `n` 个 2）→ `2^n` 个 pattern。

## Worked example

- **示例要展示的概念：** 每增加一个 bit，组合数量加倍；这个规则如何扩展到一个 byte。
- **条件与简化：** 每个位置都可独立取 `0` 或 `1`，且这里计算的是可能的 bit pattern 数，不是在指定编码下可用的字符、数值或指令数。结果的单位是 pattern 个数，不是 bytes 或存储容量。
- **输入：** 一个 3-bit sequence；每个位置各有两种可能。

| 步骤 | 操作或规则 | 中间状态 / 结果 | 解释 |
|---|---|---|---|
| 1 | 第一个 bit 有 2 种选择 | 2 patterns | `0` 或 `1` |
| 2 | 第二个 bit 为每种已有 pattern 各增加 `0`、`1` 两种后缀 | `2 × 2 = 4` patterns | `00`, `01`, `10`, `11` |
| 3 | 第三个 bit 再将组合数乘以 2 | `2 × 2 × 2 = 8` patterns | `000` 到 `111`，共 8 种 |
| 4 | 将同一规则扩展到 8 个 bit | `2^8 = 256` patterns | 一个 8-bit byte 有 256 种 bit pattern |

- **最终结果：** 3 bits 有 8 种 pattern；8 bits（1 byte）有 256 种 pattern。`00000000` 是其中一种 8-bit pattern。
- **核对方法：** 3-bit 清单 `000, 001, 010, 011, 100, 101, 110, 111` 恰有 8 项；逐位增加位置时，组合数每次翻倍。

## 有助于理解的细节

- “有 256 种 bit pattern”只是在数不同的 0/1 序列。它本身没有说明这些 pattern 代表什么。
- 某种编码规则可能只使用一部分 pattern；因此“pattern 总数”不等于任何特定格式里的字符、数值或指令总数。
- 本内容直接采用 `1 byte = 8 bits`。为减少符号歧义，学习者可见文案先写出 “bits” 和 “bytes”，不使用 `b` / `B` 缩写。

## 常见误解

| 可能的误解 | 纠正方式 | 是否需要在内容中显式呈现 |
|---|---|---|
| 8 bits 只有 8 种组合 | 每个位置都有 2 个选择，因此是 `2^8 = 256` 种。 | 是，作为 worked example 的核心。 |
| 256 种 patterns 就代表 256 个固定含义 | pattern 是位序列；含义取决于采用的表示或编码规则。 | 是，用一句边界说明连接后续模块。 |

## 简化与实现差异

- **教学模型：** 把每个 bit 看作独立的二选一位置；此模型用来数全部可能的位序列。
- **模型的限制：** 实际编码可能保留、禁止或赋予某些 pattern 特定用途；本例不讨论这些格式规则。
- **byte 的定义：** 本内容直接采用 `1 byte = 8 bits`。
- **术语选择：** 本项不使用 `nibble` 作为必要概念。若图形需要显示 4-bit group，可直接写“4-bit group”；是否加入 `nibble` 一词留到相关 brief 决定。

## 术语

| 术语 | brief 中采用的含义 | 学习者文案中的用法或解释 |
|---|---|---|
| bit | binary digit；值为 `0` 或 `1`。 | 首次出现时解释为一位二进制数据，可取 `0` 或 `1`。 |
| bit pattern | 按顺序排列的一组 bit。 | 使用“不同的 0/1 序列”帮助理解。 |
| byte | 8 bits。 | 直接写明 `1 byte = 8 bits`；这张内容不需要缩写 bit/byte 的符号。 |
| possible pattern | 在给定 bit 数下可形成的一种不同序列。 | 不把 pattern 数量说成具有固定意义的数值或字符数。 |
