# Topic experiments

本目录中的四个主题项目都是 Visual CS 制作方法的实际应用示例。它们用来展示并练习 `docs/` 里的品牌风格、内容研究、概念模型、视觉 brief、生成提示词和审稿流程；各主题的研究和图片仍需按项目要求进行专业内容校对。

这四个项目不代表已经完成发布审核的课程资源。品牌风格本身已在 [`docs/STYLE.md`](../../docs/STYLE.md) 中确立；本目录记录的是如何把它用于不同主题与受众。

| Project | Topic | Example focus |
|---|---|---|
| [stack-push-pop](stack-push-pop/) | Stack operations | 用短状态序列解释入栈、出栈和 LIFO。 |
| [sql-joins](sql-joins/) | SQL joins | 用两张表和三种 JOIN 结果解释匹配与未匹配行。 |
| [ai-evaluation](ai-evaluation/) | AI feature evaluation | 面向软件专业人士，呈现代表性案例、评分、失败切片与复测。 |
| [cpu-memory](cpu-memory/) | CPU and memory | 连接 A-level 的简化 MAR/MDR 模型与现代处理器的缓存路径；图片仍需修正，详见[项目说明](cpu-memory/README.md)。 |

新的制作项目按 [内容指南](../../docs/CONTENT_GUIDE.md)、[信息图指南](../../docs/INFOGRAPHIC_GUIDE.md) 和 [提示词指南](../../docs/IMAGE_PROMPT_GUIDE.md) 准备材料，并放在 `projects/<topic>/`。后续用于演示或改进制作方法的实验项目则放在本目录的独立主题子目录中。
